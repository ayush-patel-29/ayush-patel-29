## About Me

I work at the intersection of applied ML and systems engineering — less interested in calling a model API, more interested in what happens before and after that call.

- **Applied LLM Pipelines:** Structuring unstructured input (images, documents, text) into decision-ready output, with the model as one stage among several.
- **Agent & MCP-Style Architectures:** Composing tools and models into workflows instead of relying on single-shot prompts.
- **Retrieval & Context Engineering:** Treating what a model sees as the actual design problem — grounding output in real data rather than letting a model guess.

## Featured Projects

### [foodify.ai](https://github.com/ayush-patel-29/foodify.ai) — AI Food Label Parser
![Status](https://img.shields.io/badge/status-active-brightgreen?style=flat-square)

- **The Problem:** Food labels bury safety-relevant information (additives, allergens, quality red flags) in dense, inconsistent text that's easy to misread.
- **The Solution:** A pipeline that takes a photo of a label and returns a structured nutrition and safety report — parsing ingredients and additives into a quick, readable quality score.
- **Stack:** Python, Jupyter, LLM-based parsing, computer vision preprocessing.

### [silicon-mind](https://github.com/ayush-patel-29/silicon-mind) — Automated Newsletter Backend
![Status](https://img.shields.io/badge/status-active-brightgreen?style=flat-square)

- **The Problem:** Producing and shipping a regular AI newsletter (*The Silicon Mind*) by hand doesn't scale — content generation, formatting, and delivery are three separate failure points.
- **The Solution:** An MCP-style backend that generates HTML issues, manages the subscriber base, and handles delivery and welcome emails via Resend end-to-end.
- **Stack:** Python, MCP-style tool composition, Resend API.

### [rise-up](https://github.com/ayush-patel-29/rise-up) — GraphRAG Literature Synthesis Engine
![Status](https://img.shields.io/badge/status-in--progress-yellow?style=flat-square)

- **The Problem:** Research on the intersection of exercise and mental health is scattered across thousands of PubMed papers — synthesizing it into a usable answer normally means hours of manual literature review.
- **The Solution:** A CRAG-style retrieval system: query a local knowledge graph built from exercise/mental-health literature first, evaluate the answer quality with an LLM-as-judge, and fall back to a live PubMed search when local retrieval falls short.
- **Stack:** Python, GraphRAG, PubMed API integration, LLM-as-judge evaluation loop.

### [pygame-agent](https://github.com/ayush-patel-29/pygame-agent) — Natural-Language-to-Game Agent
![Status](https://img.shields.io/badge/status-active-brightgreen?style=flat-square)

- **The Problem:** Testing the real ceiling of LLM code generation requires more than autocomplete — it requires an agent that can write, run, and iterate on executable code.
- **The Solution:** An agent that turns natural-language instructions into working Python games, end to end.
- **Stack:** Python, agentic code generation.
